# MausamMitra

A simple and fast weather app for Nepal. Get real-time weather updates for your city at a glance.

## Features
* **Real-time:** Live weather data.
* **Simple:** No clutter, just the info you need.
* **Mobile-Friendly:** Works great on your phone.

## How to use
1. Clone the repo: `git clone [your-repo-link]`
2. Open `index.html` (or run your dev command).

## Built with
* HTML, CSS, & JavaScript
* OpenWeather API
